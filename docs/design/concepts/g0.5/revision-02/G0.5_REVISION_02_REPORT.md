## 5. Concept vs production

Concept-only: PNG overview, character poses/outfits, soft lighting, decorative plants/art, screen illustrations, camera acceptance thumbnails.  
Production-ready direction: room names/order, 34×24 envelope, material tokens, 12-agent roster, shared skeleton contract, anchor names, workstation allocation.

Chưa được coi là production: exact mesh topology, pivot/origin validation, GLB export, skinning, animation clips, waypoint/collider/door anchor runtime, Paperclip state data, responsive camera implementation.
