# Private creator voice profile

Use this template only after brainstorm mode ends. Keep the filled profile in the creator's private workspace, outside public skill payloads and examples. It is optional: infer only what the conversation supports, and leave unknown preferences unknown. The shared handoff may contain the project-specific choices needed by an editor, without exposing the entire profile.

```text

Product vocabulary file:
Humor / emotional register:
Words, flourishes, punctuation, or structures to avoid:
Project style checks:

Approved examples (exact wording, context, why it works):
Rejected examples (exact wording, creator's reason):
Spoken changes worth keeping (draft → actual read, meaning check):

Optional workflow preferences:
Writing and editing collaborators or personas:
Recording tools and available local transcription route:
Private media home and review devices:
```

Prefer the creator's sentences with careful trims over invented flourishes. A preference for one collaborator or application belongs here, not in generic public instructions. Never infer that someone wants a different model, a new tool installed, or a public example made from their recording. Revisit the profile when actual feedback contradicts it; do not accumulate every accidental ASR spelling as a voice preference.
