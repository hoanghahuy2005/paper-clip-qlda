# Office base rig provenance

`office-base-rig.glb` is an original procedural asset generated by `scripts/generate-office-rig.mjs` in this repository. No external model, texture, motion capture, or third-party artwork was used. VPD releases this generated asset under CC0 1.0. It has one skinned mesh, a shared humanoid skeleton, feet at Y=0, and nine named animation clips. All 12 Office variants clone this rig and apply role color/badge props in Three.js.

`test-rig.glb` is the separate G0 technical fixture. The Office MVP loads `office-base-rig.glb`.
