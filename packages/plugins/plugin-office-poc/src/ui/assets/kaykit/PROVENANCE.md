# KayKit Furniture Bits sample

Author: Kay Lousberg. Source: https://github.com/KayKit-Game-Assets/KayKit-Furniture-Bits-1.0 (official author repository); pack page: https://kaylousberg.itch.io/furniture-bits . License: CC0 1.0 Universal, included verbatim in `LICENSE.txt` from the same repository. Downloaded 26 November 2026 from the repository `main` raw files. Only nine selected glTF models (`couch_pillows`, `table_low`, `table_medium_long`, `chair_B`, `shelf_B_small_decorated`, `cabinet_medium_decorated`, `lamp_table`, `cactus_medium_A`, `pictureframe_medium`), their buffers and shared atlas texture are shipped. The other files in the pack are not copied. Furniture proportions and final visual acceptance remain for CEO review.

Eight more selected models from the same official `main` repository were added for the Meeting, Creative and AI Production visual pass: `shelf_B_large_decorated`, `lamp_standing`, `chair_A_wood`, `book_set`, `pictureframe_large_A`, `cactus_medium_B`, `table_medium`, and `shelf_A_big`. Each ships with its matching `.bin` and reuses the existing atlas. The repository README and bundled `LICENSE.txt` state CC0 1.0. No other pack files were copied.

Runtime loader uses the original glTF with local buffer and atlas. This is not the project-authored Office rig and carries no agent animation. The project does not claim authorship of these models.
